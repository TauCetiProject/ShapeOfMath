2. Congruence modulo an integer
   The relation a≡b (mod m) means that m divides a−b.
   Source: relies_on, p. 144

3. Involution of a finite set
   An involution of a finite set X is a map f:X→X with f(f(x))=x for all x∈X.
   Source: relies_on, p. 144

4. Fixed point of a self-map
   A fixed point of f:X→X is an x∈X satisfying f(x)=x. The fixed-point set is Fix(f)={x∈X:f(x)=x}.
   Source: relies_on, p. 144

5. Fixed-point parity lemma for finite involutions
   If f is an involution of a finite set X, then X and Fix(f) have the same cardinality modulo two.
   Source: relies_on, p. 144

6. Zagier's involution
   For a prime p≡1 (mod 4), let Sₚ={(x,y,z)∈ℤ₊³:x²+4yz=p}. Send (x,y,z) to (x+2z,z,y−x−z) if x<y−z, to (2y−x,y,x−y+z) if y−z<x<2y, and to (x−2y,x−y+z,y) if x>2y. These cases exhaust Sₚ and define an involution with the unique fixed point (1,1,(p−1)/4).
   Source: explains, p. 144, displayed map

7. Fermat's two-square theorem
   A prime p is a²+b² for integers a,b if and only if p=2 or p≡1 (mod 4).
   Source: explains, p. 144
   Note: Proves the nontrivial p≡1 mod 4 direction of the full named theorem.
