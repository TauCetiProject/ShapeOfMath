LOCATED CONCEPTS (6)

1. Host–Kra–Maass cube characterization of inverse nilsystems
   For a transitive compact metric system (X,T), with T a homeomorphism, and d≥2, let Q^[d](X) be the closure of all cubes (T^(ε·n)x)_(ε∈{0,1}^d). Then (X,T) is an inverse limit of minimal (d−1)-step nilsystems exactly when (x,y,…,y)∈Q^[d](X) implies x=y; equivalently any two cubes agreeing at all but one vertex agree at that vertex too.
   Source: introduces, Theorem 1.2, pp. 3–4; proof §§3–6
   Note: Selected complete proof inspected for cone-056.
   Origin evidence: Abstract and §1.2 present Theorem 1.2 as the paper’s new structure theorem characterizing inverse limits of nilsystems; the Host–Maass 2007 predecessor treats only order 2 and §1.2 says (1)⇒(3) is proved by methods different from that d=3 case.

2. Inverse limit of topological dynamical systems
   For compact metric systems (X_i,T_i), i∈ℕ, and factor maps π_i:X_(i+1)→X_i, the inverse limit is the subspace {(x_i):π_i(x_(i+1))=x_i for all i} of the product ∏X_i with the map (x_i)↦(T_ix_i). A system is an inverse limit of systems of a class when it is conjugate to such a limit with all (X_i,T_i) in the class.
   Source: explains, §2.3 p8
   Note: Recalled definition; not an origin claim.

3. Minimal topological dynamical system
   A compact topological dynamical system (X,T), with T a homeomorphism, is minimal if ∅ and X are its only closed subsets A with T(A)=A; equivalently every orbit {Tⁿx:n∈ℤ} is dense in X.
   Source: explains, §2.1 p6
   Note: Recalled definition; not an origin claim.

4. Topologically transitive dynamical system
   A compact topological dynamical system (X,T), with T a homeomorphism, is transitive if some point x has dense two-sided orbit {Tⁿx:n∈ℤ}; such an x is a transitive point.
   Source: explains, §2.1 p6
   Note: Recalled definition; not an origin claim.

5. Factor map of topological dynamical systems
   For compact topological dynamical systems (X,T) and (Y,S), a factor map is a continuous surjection p:X→Y with S∘p=p∘T; then (Y,S) is a factor of (X,T). A bijective factor map is a conjugacy.
   Source: explains, §2.1 p6
   Note: Recalled definition; not an origin claim.

6. Regionally proximal relation of order d
   For a compact metric system (X,T) and d≥1, (x,y)∈RP^[d] if for every δ>0 there are x′,y′∈X and n∈ℤᵈ with d(x,x′)<δ, d(y,y′)<δ and d(T^(n·ε)x′,T^(n·ε)y′)<δ for every nonempty ε⊂{1,…,d}. RP^[1] is the classical regionally proximal relation.
   Source: explains, Definition 3.2 p11
   Note: Definition as used by Shao–Ye; no priority judgment recorded.
