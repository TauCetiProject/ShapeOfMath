LOCATED CONCEPTS (5)

1. Kummer’s Bernoulli criterion for a regular prime
   For an odd prime p, p does not divide the class number of ℚ(ζ_p) if and only if p divides none of the numerators of B₂,B₄,…,B_(p−3), written in lowest terms. Such a prime is called regular.
   Source: explains, Lecture VI, (2F), pp.102–103
   Note: Exposition of Kummer's 1850 criterion; not a priority claim.

2. Kummer’s reduction of p | h(ℚ(ζ_p)) to the relative class number
   For an odd prime p, p divides the class number of ℚ(ζ_p) if and only if p divides the relative class number h⁻(p)=h(ℚ(ζ_p))/h(ℚ(ζ_p+ζ_p⁻¹)).
   Source: explains, Lecture VI, (1E), p.99
   Note: Statement attributed to Kummer (1850); proof not given.

3. Kummer’s power-sum criterion for the relative class number
   For an odd prime p, p divides the relative class number h⁻(p) of ℚ(ζ_p) if and only if p² divides ∑_(j=1)^(p−1) j^(2k) for some integer k with 1≤k≤(p−3)/2.
   Source: explains, Lecture VI, (2A) and sketched proof, p.99
   Note: Attributed to Kummer (1850); proof sketched.

4. Von Staudt–Clausen theorem
   For every k≥1, B_(2k)+∑1/p, summed over the primes p with (p−1) dividing 2k, is an integer. Hence the reduced denominator of B_(2k) is the squarefree product of those primes.
   Source: explains, Lecture VI, (2D), p.102
   Note: Statement; proof referred to Hardy–Wright.

5. Power-sum congruence for Bernoulli numbers
   For integers m≥2 and k≥1, write B_(2k)=N_(2k)/D_(2k) in lowest terms with D_(2k)>0. Then m·N_(2k)≡D_(2k)·∑_(j=1)^(m−1) j^(2k) modulo m².
   Source: explains, Lecture VI, (2E) formula (2.13), p.102
   Note: Statement; not a priority claim.
