RECURSIVE PREREQUISITE EXPERIMENTS

Sets, natural numbers, elementary logic and finite arithmetic are primitive vocabulary. Recursion expands every other recorded prerequisite; formal set-theoretic encodings, ZFC axioms, and size foundations for large categories are not part of this pedagogical route.

Each listed concept has an explicit immediate-prerequisite review. The complete flag is not inferred from reachability.
Edges are transitively reduced. Original redundant edges, rationales, evidence and retained alternative paths are in the curation history.

DRINFELD CENTER OF A MONOIDAL CATEGORY
16 concepts including the root; 20 edges; 9 levels below the root.
Recorded cone fully reviewed: True
Baseline leaves: set

Drinfeld center of a monoidal category
For a monoidal category C, its center Z(C) has objects (X,c), where c is a half-braiding on X, and morphisms f:X→X′ compatible with the half-braidings. Tensoring these pairs makes Z(C) braided; C itself need not be braided.
Immediate prerequisites: Half-braiding; Braided monoidal category
Reference: egno-tensor-categories-2015, Definition 7.13.1 and Remark 7.13.3.
Review: The input category need only be monoidal. Braided categories describe the resulting structure on its center, not an assumption on the input.

Braided monoidal category
A monoidal category with natural isomorphisms c(X,Y):X⊗Y→Y⊗X satisfying the two hexagon identities.
Immediate prerequisites: Monoidal category
Reference: egno-tensor-categories-2015, Definition 8.1.1.

Half-braiding
For an object X of a monoidal category C, a natural family of isomorphisms c_Y:X⊗Y→Y⊗X, compatible with tensor products and the unit: c_{Y⊗Z}=(id_Y⊗c_Z)∘(c_Y⊗id_Z), with associators inserted.
Immediate prerequisites: Monoidal category
Reference: egno-tensor-categories-2015, Definition 7.13.1.
Review: Our c_Y:X⊗Y→Y⊗X is the inverse-direction convention to EGNO’s γ_Y:Y⊗X→X⊗Y; retain the associators.

Monoidal category
A category C with a tensor bifunctor C×C→C, a unit object, and natural associativity and unit isomorphisms satisfying the pentagon and triangle identities.
Immediate prerequisites: Bifunctor; Natural isomorphism
Reference: egno-tensor-categories-2015, Definitions 2.1.1 and 2.2.8.
Review: The pentagon and triangle equations are part of this definition; a coherence theorem is not needed to state it.

Bifunctor
A functor C×D→E from a product of two categories to another category.
Immediate prerequisites: Product of categories; Functor
Reference: egno-tensor-categories-2015, §2.1, tensor product bifunctor.

Natural isomorphism
A natural transformation whose component at every object is an isomorphism.
Immediate prerequisites: Natural transformation; Isomorphism in a category
Reference: stacks-project, §4.3, Isomorphisms of functors.

Isomorphism in a category
A morphism f:X→Y having an inverse g:Y→X, so gf=id_X and fg=id_Y.
Immediate prerequisites: Category
Reference: stacks-project, §4.2, Definition 4.2.8.

Natural transformation
A family of maps between the values of two functors, commuting with every morphism in their source category.
Immediate prerequisites: Functor
Reference: stacks-project, §4.3, Morphisms of functors.

Product of categories
C×D has pairs of objects and pairs of morphisms, with identities and composition defined componentwise.
Immediate prerequisites: Category
Reference: stacks-project, Categories chapter, Products of categories.

Functor
A map of categories preserving objects, morphisms, identities and composition.
Immediate prerequisites: Category
Reference: stacks-project, §4.3, Definition of a functor.

Category
Objects and morphisms with associative composition and identity morphisms.
Immediate prerequisites: Composition of functions; Cartesian product of sets
Reference: stacks-project, §4.2, Definition 4.2.1.
Review: Composition is defined on pairs of composable morphisms, not a single everywhere-defined operation on all arrows. Size conventions are suppressed in this experiment.

Cartesian product of sets
A×B is the set of ordered pairs (a,b) with a∈A and b∈B.
Immediate prerequisites: Ordered pair
Reference: lebl-basic-analysis-2026, Definition 0.3.10.

Composition of functions
For f:A→B and g:B→C, the composite g∘f:A→C sends x to g(f(x)).
Immediate prerequisites: Function between sets
Reference: lebl-basic-analysis-2026, Definition 0.3.18.

Function between sets
An assignment taking each element of a specified domain set to exactly one element of a specified codomain set.
Immediate prerequisites: Set
Reference: lebl-basic-analysis-2026, §0.3.3.
Review: Use the assignment description, rather than requiring a set-theoretic encoding of its graph.

Ordered pair
A pair (x,y) with distinguished first and second entries; (x,y)=(x′,y′) exactly when x=x′ and y=y′.
Immediate prerequisites: Set
Reference: lebl-basic-analysis-2026, §0.3.3, ordered tuples.

Set
A collection of distinct elements, regarded as one object.
Immediate prerequisites: None at the stated primitive baseline.
Reference: lebl-basic-analysis-2026, §0.3.1.
Review: Primitive at this pedagogical baseline; no ZFC axioms or formal set encoding is required.

CHEBYSHEV'S INEQUALITY
46 concepts including the root; 71 edges; 17 levels below the root.
Recorded cone fully reviewed: True
Baseline leaves: natural-number, set

Chebyshev's inequality
If EX²<∞ and t>0, then P(abs(X−EX)≥t)≤Var(X)/t².
Immediate prerequisites: Variance of a real random variable; Markov’s inequality for nonnegative random variables
Reference: durrett-probability-2019, §1.6, Theorem 1.6.4 and formula (1.6.1).
Review: Apply Markov to (X−EX)². Its measurability follows by expressing level events as unions of preimages of real intervals; the elementary calculation stays in this note.

Markov’s inequality for nonnegative random variables
If Y is a nonnegative integrable real random variable and t>0, then P(Y≥t)≤E[Y]/t.
Immediate prerequisites: Expectation of an integrable real random variable; Monotonicity of the Lebesgue integral
Reference: durrett-probability-2019, Theorem 1.6.4 and following remark.
Review: Integrate t·1_{Y≥t}≤Y. The integral of the indicator multiple is part of the simple-function integral formula.

Variance of a real random variable
If EX²<∞, then Var(X)=E[(X−EX)²].
Immediate prerequisites: Expectation of an integrable real random variable; Linearity of the Lebesgue integral
Reference: durrett-probability-2019, §1.6, variance.
Review: Finite second moment implies integrability using |x|≤1+x²; no Hölder or Cauchy–Schwarz prerequisite is needed for this route.

Expectation of an integrable real random variable
If E abs(X)=∫abs(X)dP<∞, the expectation of X is EX=∫X dP.
Immediate prerequisites: Real-valued random variable; Lebesgue integral
Reference: durrett-probability-2019, §1.6, expectation.

Linearity of the Lebesgue integral
If f and g are integrable real functions and a,b are real scalars, then af+bg is integrable and ∫(af+bg)dμ=a∫f dμ+b∫g dμ.
Immediate prerequisites: Lebesgue integral
Reference: durrett-probability-2019, §1.4, linearity properties.
Review: Extend finite linearity from simple functions to the nonnegative integral, then to integrable positive and negative parts.

Monotonicity of the Lebesgue integral
If 0≤f≤g are measurable functions on a measure space, then ∫f dμ≤∫g dμ, allowing infinite integrals.
Immediate prerequisites: Lebesgue integral
Reference: durrett-probability-2019, §1.4, monotonicity properties.
Review: For nonnegative functions, every simple lower approximation to f is also a lower approximation to g.

Lebesgue integral
For measurable f≥0, ∫f dμ is the supremum of integrals of nonnegative simple functions below f. For signed f with ∫abs(f)dμ<∞, define ∫f=∫f⁺−∫f⁻.
Immediate prerequisites: Measure; Measurable simple real function
Reference: durrett-probability-2019, §1.4, Steps 1–4.
Review: Use the supremum of nonnegative simple integrals, then positive and negative parts. No convergence theorem is required for this definition.

Real-valued random variable
A real-valued random variable is a measurable map from a probability space to ℝ with its Borel σ-algebra.
Immediate prerequisites: Probability space; Measurable map between measurable spaces; Borel σ-algebra on the real line
Reference: durrett-probability-2019, §§1.2–1.3.
Review: The codomain is the real line with its Borel σ-algebra.

Measurable simple real function
A measurable real function with finite range. It can be written as a finite sum ∑ a_i 1_{A_i} with measurable level sets A_i.
Immediate prerequisites: Measurable map between measurable spaces; Borel σ-algebra on the real line; Finite set; Indicator function of a subset
Reference: durrett-probability-2019, §1.4, Step 1.
Review: Finite range and the equivalent indicator-sum description are one concept.

Probability space
A probability space is (Ω,𝔽,P), where 𝔽 is a σ-algebra on Ω and P is a measure on 𝔽 with P(Ω)=1.
Immediate prerequisites: Measure
Reference: durrett-probability-2019, §1.1.
Review: Normalization P(Ω)=1 is part of the definition.

Borel σ-algebra on the real line
The σ-algebra on ℝ generated by the open intervals.
Immediate prerequisites: σ-algebra generated by a family of subsets; Open interval in the real line
Reference: durrett-probability-2019, §1.1, Borel sets.
Review: Interval generators avoid making general topological spaces a prerequisite for this particular σ-algebra.

Finite set
A set X is finite if it is bijective with {1,…,n} for some integer n≥0; its cardinality is n.
Immediate prerequisites: Bijection between sets; Natural number
Reference: lebl-basic-analysis-2026, §0.3.5.

Indicator function of a subset
For A⊆Ω, the real function 1_A is 1 on A and 0 on its complement.
Immediate prerequisites: Complement of a subset; Real number
Reference: durrett-probability-2019, §1.2, indicator functions.

Measurable map between measurable spaces
A function for which the preimage of each measurable subset of the codomain is measurable in the domain.
Immediate prerequisites: Measurable space; Preimage of a subset under a function
Reference: durrett-probability-2019, §1.3.

Measure
A measure μ maps a σ-algebra to [0,∞], sends ∅ to 0, and satisfies μ(⋃ₙAₙ)=∑ₙμ(Aₙ) for every pairwise disjoint sequence of measurable sets.
Immediate prerequisites: σ-algebra; Sum of a nonnegative series; Disjoint sets
Reference: durrett-probability-2019, §1.1.
Review: Countable additivity and the extended nonnegative codomain are definition inputs.

Bijection between sets
A function for which each element of the codomain is the image of exactly one element of the domain.
Immediate prerequisites: Function between sets
Reference: lebl-basic-analysis-2026, Definition 0.3.17.

Disjoint sets
Two sets are disjoint when they have no common element; a family is pairwise disjoint when every two distinct members are disjoint.
Immediate prerequisites: Set
Reference: lebl-basic-analysis-2026, §0.3.1.

Measurable space
A set equipped with a specified σ-algebra of subsets.
Immediate prerequisites: σ-algebra
Reference: durrett-probability-2019, §1.1.

Open interval in the real line
For real a<b, the set (a,b)={x∈ℝ:a<x<b}.
Immediate prerequisites: Real number
Reference: lebl-basic-analysis-2026, §1.4.

Preimage of a subset under a function
For f:A→B and E⊆B, f⁻¹(E)={x∈A:f(x)∈E}.
Immediate prerequisites: Function between sets; Subset
Reference: durrett-probability-2019, §1.3.

Sum of a nonnegative series
For aₙ≥0, define ∑ₙ≥1aₙ as the supremum of its finite partial sums; the value may be infinite.
Immediate prerequisites: Real sequence; Extended nonnegative real numbers
Reference: lebl-basic-analysis-2026, §2.5.

σ-algebra generated by a family of subsets
The smallest σ-algebra containing that family, equivalently the intersection of all σ-algebras on the ambient set that contain it.
Immediate prerequisites: σ-algebra; Intersection of a family of sets
Reference: durrett-probability-2019, §1.1.
Review: Use the intersection definition; no general topology is assumed.

Extended nonnegative real numbers
The nonnegative real numbers together with a greatest element ∞. Sums involving ∞ equal ∞, and 0·∞ is taken to be 0 when integrating simple functions.
Immediate prerequisites: Real number
Reference: lebl-basic-analysis-2026, §1.2, extended real numbers.

Intersection of a family of sets
Inside a specified ambient set, the elements belonging to every member of the family.
Immediate prerequisites: Set
Reference: lebl-basic-analysis-2026, §0.3.1.

Real sequence
A real sequence is a function a:ℕ₊→ℝ, written (aₙ)ₙ≥1.
Immediate prerequisites: Real number; Sequence in a set
Reference: lebl-basic-analysis-2026, §2.1.

σ-algebra
A σ-algebra on Ω contains Ω and is closed under complements in Ω and countable unions.
Immediate prerequisites: Complement of a subset; Union of a family of sets; Sequence in a set
Reference: durrett-probability-2019, §1.1.
Review: Countable unions are indexed by a sequence; closure conditions are part of the definition.

Complement of a subset
For A⊆Ω, its complement Ω∖A consists of the elements of Ω that do not belong to A.
Immediate prerequisites: Subset
Reference: lebl-basic-analysis-2026, §0.3.1.

Real number
A real number is an element of a complete ordered field ℝ; completeness means every nonempty subset bounded above has a least upper bound.
Immediate prerequisites: Ordered field; Least upper bound in a partially ordered set
Reference: lebl-basic-analysis-2026, §1.2.

Sequence in a set
A function from the natural numbers, or the positive natural numbers, to that set.
Immediate prerequisites: Function between sets; Natural number
Reference: lebl-basic-analysis-2026, §2.1.

Union of a family of sets
The set of elements belonging to at least one member of the family.
Immediate prerequisites: Set
Reference: lebl-basic-analysis-2026, §0.3.1.

Least upper bound in a partially ordered set
For A⊆P, its least upper bound is an upper bound s satisfying s≤b for every upper bound b of A, when such an s exists.
Immediate prerequisites: Partial order
Reference: lebl-basic-analysis-2026, Definitions 1.1.2–1.1.3.

Natural number
One of 0, 1, 2, …; natural numbers count finite collections.
Immediate prerequisites: None at the stated primitive baseline.
Reference: lebl-basic-analysis-2026, §§0.3.1–0.3.2.
Review: Primitive counting vocabulary at this baseline. Our ℕ includes 0; Lebl uses ℕ for positive integers.

Ordered field
A field with a total order preserved by addition, in which the product of two positive elements is positive.
Immediate prerequisites: Field; Total order
Reference: lebl-basic-analysis-2026, Definition 1.1.6.

Field
A commutative ring in which 1≠0 and every nonzero element is invertible.
Immediate prerequisites: Commutative ring with identity
Reference: milne-galois-notes, Definition 1.1.

Total order
A partial order in which any two elements are comparable.
Immediate prerequisites: Partial order
Reference: lebl-basic-analysis-2026, Definition 1.1.1.

Commutative ring with identity
An abelian group under addition, together with an associative commutative multiplication with identity, distributing over addition. The zero ring is allowed.
Immediate prerequisites: Abelian group
Reference: milne-galois-notes, Chapter 1, Rings.

Partial order
A reflexive, antisymmetric and transitive binary relation, usually written ≤.
Immediate prerequisites: Binary relation on a set
Reference: lebl-basic-analysis-2026, §1.1, ordered sets.

Abelian group
A group whose operation is commutative.
Immediate prerequisites: Group
Reference: milne-galois-notes, Chapter 1, opening ring definition.
Review: The additive group is required to be commutative.

Binary relation on a set
A subset R⊆S×S; writing xRy means (x,y)∈R.
Immediate prerequisites: Cartesian product of sets; Subset
Reference: lebl-basic-analysis-2026, §0.3.4.

Group
A set with an associative binary operation, an identity element, and a two-sided inverse for each element.
Immediate prerequisites: Binary operation on a set
Reference: milne-galois-notes, Chapter 1, opening ring definition.
Review: The source assumes the group axioms; the full short definition is supplied in this catalogue.

Subset
A⊆B means every element of A is an element of B.
Immediate prerequisites: Set
Reference: lebl-basic-analysis-2026, §0.3.1.

Binary operation on a set
A function S×S→S.
Immediate prerequisites: Function between sets; Cartesian product of sets
Reference: milne-galois-notes, Chapter 1, opening ring and field definitions.
Review: The source uses binary operations; the short definition is supplied in this catalogue.

Cartesian product of sets
A×B is the set of ordered pairs (a,b) with a∈A and b∈B.
Immediate prerequisites: Ordered pair

Immediate prerequisites: Set

Immediate prerequisites: Set
