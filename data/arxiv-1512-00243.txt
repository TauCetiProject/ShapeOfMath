REQUIRED CONCEPT FRONTIER (10)

- Bregman firmly nonexpansive map: For a differentiable convex f, a map T:C→C is Bregman firmly nonexpansive if ⟨Df(Tx)−Df(Ty),Tx−Ty⟩≤⟨Df(x)−Df(y),Tx−Ty⟩ for every x,y∈C.
- Bregman resolvent of a mixed equilibrium problem: For a differentiable convex f, the mixed equilibrium resolvent sends x to the set of z∈C satisfying Θ(z,y)+φ(y)−φ(z)+⟨Df(z)−Df(x),y−z⟩≥0 for every y∈C. Domain, uniqueness and existence depend on the hypotheses.
- Coercive real functional: A real or extended-real functional f on a normed space is coercive if f(x)→+∞ as ||x||→∞, equivalently each finite sublevel set is bounded.
- Composition theorem for Bregman strongly nonexpansive maps: Suppose f is Legendre, bounded and uniformly Fréchet differentiable on bounded sets, totally convex on bounded sets, with Df* bounded on bounded subsets of E*=domf*. If T₁,…,T_N:C→C are Bregman strongly nonexpansive and their asymptotic fixed sets have nonempty intersection, their composition is Bregman strongly nonexpansive and its asymptotic fixed set equals that intersection.
- Fenchel–Young gap: For a proper convex f on a Banach space, its Fenchel–Young gap is V_f(x,x*)=f(x)+f*(x*)−⟨x*,x⟩≥0; when f* is differentiable and the Legendre duality identities hold, V_f(x,x*)=D_f(x,Df*(x*)).
- Reflexive Banach space: A Banach space X for which the canonical isometric map X→X**, sending x to the functional ℓ↦ℓ(x), is onto.
- Scalar convergence lemma for vanishing convex recurrences: If a_n≥0,0<α_n<1, ∑α_n=∞ and a_{n+1}≤(1−α_n)a_n+β_n, then a_n→0 provided limsup β_n/α_n≤0 or ∑|β_n|<∞.
- Total convexity and Bregman sequential consistency: For a differentiable convex function whose effective domain contains at least two points, total convexity on bounded sets is equivalent to sequential consistency of its Bregman distance.
- Uniform continuity of a uniformly differentiable convex gradient: If f:E→ℝ is convex, bounded on bounded sets and uniformly Fréchet differentiable on bounded sets, then Df:E→E* is uniformly norm-continuous on bounded sets.
- Variational characterization of a Bregman projection: For differentiable strictly convex f on a Banach space and convex C, z∈C minimizes D_f(·,x) if and only if ⟨Df(x)−Df(z),y−z⟩≤0 for all y∈C. Such z satisfies D_f(y,z)+D_f(z,x)≤D_f(y,x).

LOCATED CONCEPTS (19)

1. Bregman projection onto a convex set
   Given a differentiable convex f and a nonempty closed convex C⊂dom f, the Bregman projection of x is the unique minimizer of y↦D_f(y,x) over C whenever that minimizer exists and is unique. Existence and uniqueness require additional hypotheses.
   Source: relies_on, §2–3
   Note: Projections and their variational inequality.

2. Bregman strongly nonexpansive map
   Relative to a differentiable convex f, T:C→C is Bregman strongly nonexpansive with respect to its nonempty asymptotic fixed set F̂ if D_f(p,Tx)≤D_f(p,x) for p∈F̂ and, for bounded x_n, D_f(p,x_n)−D_f(p,Tx_n)→0 implies D_f(x_n,Tx_n)→0.
   Source: relies_on, §2–3
   Note: Main mapping class, imported [7],[26].

3. Bregman firmly nonexpansive map
   For a differentiable convex f, a map T:C→C is Bregman firmly nonexpansive if ⟨Df(Tx)−Df(Ty),Tx−Ty⟩≤⟨Df(x)−Df(y),Tx−Ty⟩ for every x,y∈C.
   Source: relies_on, Lemmas2.14–2.15
   Note: Resolvent estimates.

4. Bregman resolvent of a mixed equilibrium problem
   For a differentiable convex f, the mixed equilibrium resolvent sends x to the set of z∈C satisfying Θ(z,y)+φ(y)−φ(z)+⟨Df(z)−Df(x),y−z⟩≥0 for every y∈C. Domain, uniqueness and existence depend on the hypotheses.
   Source: relies_on, §2–3
   Note: Mixed equilibrium regularization.

5. Total convexity of a functional on bounded sets
   A differentiable convex f is totally convex on bounded sets if, for every bounded B⊂int(dom f) and t>0, inf{D_f(y,x):x∈B,y∈dom f,||y−x||=t}>0 whenever the constraint set is nonempty.
   Source: relies_on, §2–3
   Note: Convert vanishing Bregman gaps into norm convergence.

6. Fenchel conjugate of a real convex functional
   For f:E→(−∞,∞], its Fenchel conjugate is f*(x*)=sup_{x∈E}(⟨x*,x⟩−f(x)) on the continuous dual E*.
   Source: relies_on, §1–3
   Note: Dual-gradient iteration.

7. Reflexive Banach space
   A Banach space X for which the canonical isometric map X→X**, sending x to the functional ℓ↦ℓ(x), is onto.
   Source: relies_on, Theorem3.1
   Note: Weakly convergent subsequences.

8. Uniformly continuous map between metric spaces
   A map f:X→Y between metric spaces such that for every ε>0 some δ>0 satisfies d_Y(f(x),f(y))<ε whenever d_X(x,y)<δ. The same δ works at every point.
   Source: relies_on, Theorem3.1
   Note: Passing asymptotic regularity through finite compositions.

9. Fréchet derivative between normed spaces
   The Fréchet derivative of f at x is a bounded linear map A with ∥f(x+h)−f(x)−Ah∥/∥h∥→0 as h→0.
   Source: relies_on, §2–3
   Note: Uniform differentiability hypothesis and gradient continuity.

10. Mixed equilibrium problem
   For a convex set C, a bifunction Θ:C×C→ℝ and φ:C→ℝ, the mixed equilibrium problem asks for x∈C such that Θ(x,y)+φ(y)≥φ(x) for every y∈C.
   Source: explains, §1
   Note: Blum–Oettli and Noor–Oettli credited as earlier origins; no new vocabulary origin assigned here.

11. Legendre function on a Banach space
   A proper lower-semicontinuous convex function on a real Banach space is Legendre if it is both essentially smooth and essentially strictly convex.
   Source: relies_on, §2;Theorem3.1
   Note: Use the primary Banach definition, keeping printed L1/L2 domain errors explicit.

12. Total convexity and Bregman sequential consistency
   For a differentiable convex function whose effective domain contains at least two points, total convexity on bounded sets is equivalent to sequential consistency of its Bregman distance.
   Source: relies_on, Lemma2.5;proofTheorem3.1
   Note: Repeatedly convert Bregman convergence into norm convergence.

13. Uniform continuity of a uniformly differentiable convex gradient
   If f:E→ℝ is convex, bounded on bounded sets and uniformly Fréchet differentiable on bounded sets, then Df:E→E* is uniformly norm-continuous on bounded sets.
   Source: relies_on, Lemma2.8;proofTheorem3.1
   Note: Control differences of gradients from differences of iterates.

14. Variational characterization of a Bregman projection
   For differentiable strictly convex f on a Banach space and convex C, z∈C minimizes D_f(·,x) if and only if ⟨Df(x)−Df(z),y−z⟩≤0 for all y∈C. Such z satisfies D_f(y,z)+D_f(z,x)≤D_f(y,x).
   Source: relies_on, Lemma2.10;proofTheorem3.1
   Note: The exact Bregman projection inequality used in the printed argument.

15. Fenchel–Young gap
   For a proper convex f on a Banach space, its Fenchel–Young gap is V_f(x,x*)=f(x)+f*(x*)−⟨x*,x⟩≥0; when f* is differentiable and the Legendre duality identities hold, V_f(x,x*)=D_f(x,Df*(x*)).
   Source: relies_on, Equation2.3;proofTheorem3.1
   Note: Convexity in the dual variable yields estimates for dual convex combinations.

If T₁,…,T_N:C→C are Bregman strongly nonexpansive and their asymptotic fixed sets have nonempty intersection, their composition is Bregman strongly nonexpansive and its asymptotic fixed set equals that intersection.
   Source: relies_on, Lemma2.11;Theorem3.1

17. Scalar convergence lemma for vanishing convex recurrences
   If a_n≥0,0<α_n<1, ∑α_n=∞ and a_{n+1}≤(1−α_n)a_n+β_n, then a_n→0 provided limsup β_n/α_n≤0 or ∑|β_n|<∞.
   Source: relies_on, Lemma2.16;final proofTheorem3.1

18. Uniform Fréchet differentiability on bounded sets
   A differentiable real function f on a Banach space is uniformly Fréchet differentiable on bounded sets if for every bounded B, sup_{x∈B,||h||=1}|(f(x+th)−f(x))/t−Df(x)h|→0 as t→0.
   Source: relies_on, Theorem3.1
   Note: Uniform smoothness is an explicit main assumption.

19. Coercive real functional
   A real or extended-real functional f on a normed space is coercive if f(x)→+∞ as ||x||→∞, equivalently each finite sublevel set is bounded.
   Source: relies_on, Definition2.4;Theorem3.1
   Note: Coercivity is weaker than the supercoercivity used inLemma2.14 proof.

ADDITIONAL PREREQUISITES (61)

- Abelian group [definition]: A group whose operation is commutative.
- Asymptotic fixed point of a Banach-space map [definition]: For T:C→C in a Banach space, p∈C is an asymptotic fixed point if some bounded sequence x_n∈C converges weakly to p while ||x_n−Tx_n||→0.
- Banach space [definition]: A real or complex normed vector space complete for the metric induced by its norm.
- Bijection between sets [definition]: A function for which each element of the codomain is the image of exactly one element of the domain.
- Binary operation on a set [definition]: A function S×S→S.
- Binary relation on a set [definition]: A subset R⊆S×S; writing xRy means (x,y)∈R.
- Bounded linear functional [definition]: A linear map from a real or complex normed vector space to its scalar field satisfying |ℓ(x)|≤C∥x∥ for one finite C and every x.
- Bounded linear operator [definition]: A linear map T:X→Y between normed vector spaces is bounded if ∥Tx∥≤C∥x∥ for one finite constant C and every x∈X.
- Bregman distance of a differentiable convex functional [definition]: For a proper convex functional f differentiable on int(dom f), D_f(x,y)=f(x)−f(y)−⟨Df(y),x−y⟩ for x∈dom f and y∈int(dom f). It need not be symmetric or satisfy the triangle inequality.
- Cartesian product of sets [definition]: A×B is the set of ordered pairs (a,b) with a∈A and b∈B.
- Cauchy sequence in a metric space [definition]: A sequence (xₙ) in a metric space (X,d) is Cauchy if for every ε>0 there is N such that d(xₙ,xₘ)<ε whenever n,m≥N.
- Closure of a subset of a topological space [definition]: The closure of A is the intersection of all closed subsets containing A; a set is closed when its complement is open.
- Commutative ring with identity [definition]: An abelian group under addition, together with an associative commutative multiplication with identity, distributing over addition. The zero ring is allowed.
- Complement of a subset [definition]: For A⊆Ω, its complement Ω∖A consists of the elements of Ω that do not belong to A.
- Complete metric space [definition]: A metric space is complete if every Cauchy sequence in it converges to a point of that same space.
- Complex number [definition]: A complex number is a pair of real numbers, written a+bi. Addition is componentwise and multiplication is (a+bi)(c+di)=(ac−bd)+(ad+bc)i, so i²=−1.
- Continuous dual of a normed vector space [definition]: The vector space X* of bounded linear maps X→its scalar field, with norm ‖ℓ‖=sup_{‖x‖≤1}|ℓ(x)|.
- Convergence of a sequence in a metric space [definition]: A sequence (xₙ) in a metric space (X,d) converges to x∈X if for every ε>0 there is N such that d(xₙ,x)<ε whenever n≥N.
- Convex function on a convex subset of a real vector space [definition]: A function f:C→R on a convex subset of a real vector space satisfying f((1−t)x+ty)≤(1−t)f(x)+tf(y) for x,y∈C and 0≤t≤1. Unlike the separate interval-convex-function identity, the domain may be infinite-dimensional.
- Convex subdifferential on a Banach space [definition]: For a proper convex f:X→(−∞,∞] on a real Banach space, ∂f(x)={x*∈X*:f(y)≥f(x)+⟨x*,y−x⟩ for all y∈X}, with empty value outside domf.
- Convex subset of a real vector space [definition]: A subset C of a real vector space is convex if (1−t)x+ty∈C whenever x,y∈C and0≤t≤1. The vector space may be infinite-dimensional.
- Essential smoothness of a Banach convex function [definition]: A proper lower-semicontinuous convex function on a real Banach space is essentially smooth if its convex subdifferential is single-valued and locally bounded on its domain.
- Essential strict convexity in Banach space [definition]: A proper lower-semicontinuous convex function f on a real Banach space is essentially strictly convex if (∂f)⁻¹ is locally bounded on its domain and f is strictly convex on every convex subset of dom∂f.
- Extended nonnegative real numbers [definition]: The nonnegative real numbers together with a greatest element ∞. Sums involving ∞ equal ∞, and 0·∞ is taken to be 0 when integrating simple functions.
- Field [definition]: A commutative ring in which 1≠0 and every nonzero element is invertible.
- Finite set [definition]: A set X is finite if it is bijective with {1,…,n} for some natural number n≥0; its cardinality is n.
- Fixed point of a self-map [definition]: A fixed point of f:X→X is an x∈X satisfying f(x)=x. The fixed-point set is Fix(f)={x∈X:f(x)=x}.
- Function between sets [definition]: An assignment taking each element of a specified domain set to exactly one element of a specified codomain set.
- Group [definition]: A set with an associative binary operation, an identity element, and a two-sided inverse for each element.
- Gâteaux derivative of a real functional [definition]: A functional f on a real normed space has Gâteaux derivative Df(x)∈E* if (f(x+th)−f(x))/t→Df(x)[h] for every direction h as t→0.
- Intersection of a family of sets [definition]: Inside a specified ambient set, the elements belonging to every member of the family.
- Least upper bound in a partially ordered set [definition]: For A⊆P, its least upper bound is an upper bound s satisfying s≤b for every upper bound b of A, when such an s exists.
- Limit of a function between metric spaces [definition]: For f defined near an accumulation point a of a metric space, lim_{x→a}f(x)=L means that for every ε>0 there is δ>0 such that 0<d(x,a)<δ implies d(f(x),L)<ε.
- Limit of a real sequence [definition]: A sequence (aₙ) converges to L∈ℝ if for every ε>0 there is N such that n≥N implies abs(aₙ−L)<ε.
- Linear map between vector spaces [definition]: A map between vector spaces over the same field preserving addition and scalar multiplication.
- Local boundedness of a set-valued map [definition]: A map T:X⇒Y into a normed space is locally bounded at x if some neighborhood U of x has bounded union ⋃_{u∈U}T(u). It is locally bounded on its domain if this holds at every x with T(x)≠∅.
- Lower semicontinuous extended-real function [definition]: A function u:X→(−∞,∞] on a topological space is lower semicontinuous if {x:u(x)>a} is open for every real a.
- Metric induced by a norm [construction]: The metric induced by a norm on a real or complex vector space is d(x,y)=‖x−y‖.
- Metric space [definition]: A set X with a function d:X×X→[0,∞) such that d(x,y)=0 exactly when x=y, d(x,y)=d(y,x), and d(x,z)≤d(x,y)+d(y,z).
- Modulus of a complex number [definition]: For z=a+bi, its modulus is the nonnegative real number |z|=√(a²+b²).
- Natural number [definition]: One of 0, 1, 2, …; natural numbers count finite collections.
- Nonnegative real square root [definition]: For t≥0, √t is the unique real number y≥0 satisfying y²=t.
- Normed vector space [definition]: A real or complex vector space X with a function ∥·∥:X→[0,∞) that is positive except at zero, absolutely homogeneous, and subadditive.
- Operator norm of a bounded linear operator [definition]: For a bounded linear map T:X→Y between normed spaces, ∥T∥=sup{∥Tx∥:∥x∥≤1}.
- Ordered field [definition]: A field with a total order preserved by addition, in which the product of two positive elements is positive.
- Ordered pair [definition]: A pair (x,y) with distinguished first and second entries; (x,y)=(x′,y′) exactly when x=x′ and y=y′.
- Partial order [definition]: A reflexive, antisymmetric and transitive binary relation, usually written ≤.
- Proper convex extended-real functional [definition]: A function R:V→(−∞,∞] on a real vector space is proper if it is finite somewhere and is convex if R((1−t)x+ty)≤(1−t)R(x)+tR(y) for 0≤t≤1.
- Real number [definition]: A real number is an element of a complete ordered field ℝ; completeness means every nonempty subset bounded above has a least upper bound.
- Real sequence [definition]: A real sequence is a function a:ℕ₊→ℝ, written (aₙ)ₙ≥1.
- Sequence in a set [definition]: A function from the natural numbers, or the positive natural numbers, to that set.
- Sequential consistency of a Bregman distance [definition]: For differentiable convex f, sequential consistency means that bounded x_n and D_f(y_n,x_n)→0 imply ||y_n−x_n||→0.
- Set [definition]: A collection of distinct elements, regarded as one object.
- Strictly convex function [definition]: A real-valued or extended-real function f on a real vector space is strictly convex if f((1−t)x+ty)<(1−t)f(x)+tf(y) for distinct x,y in its effective domain and0<t<1.
- Subset [definition]: A⊆B means every element of A is an element of B.
- Sum of a nonnegative series [definition]: For aₙ≥0, define ∑ₙ≥1aₙ as the supremum of its finite partial sums; the value may be infinite.
- Topological space [definition]: A set X with a family τ of subsets, called open sets, containing ∅ and X and closed under arbitrary unions and finite intersections.
- Total order [definition]: A partial order in which any two elements are comparable.
- Union of a family of sets [definition]: The set of elements belonging to at least one member of the family.
- Vector space [definition]: An abelian group with scalar multiplication by a field satisfying a(v+w)=av+aw, (a+b)v=av+bv, (ab)v=a(bv), and 1v=v.
- Weak convergence in a Banach space [definition]: A sequence xₙ converges weakly to x if ℓ(xₙ)→ℓ(x) for every bounded linear functional ℓ on the space.
