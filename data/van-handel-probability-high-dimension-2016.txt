LOCATED CONCEPTS (4)

1. McDiarmid bounded differences inequality
   For independent variablesX_i and an integrable realF whose value changes by at mostc_i when only coordinatei changes, P(F−EF≥t)≤exp(−2t²/∑c_i²) for t>0.
   Source: explains, §3.2, Theorem 3.11
   Note: Proof via Azuma–Hoeffding martingale method; inspected for cone-095.

2. Gaussian increment comparison for expected suprema
   For centered separable Gaussian processes(X_t),(Y_t) on the same index set with E(X_s−X_t)²≤E(Y_s−Y_t)² for all s,t and finite expected suprema, E sup_tX_t≤E sup_tY_t.
   Source: explains, §6.1, Theorem 6.8 (Slepian–Fernique)
   Note: Finite-dimensional statement proved by Gaussian interpolation; separable extension via §5.3.

3. Rademacher symmetrization of a centered empirical supremum
   For independent identically distributedX_i, an integrably bounded separable classF of real measurable functions, and independent Rademacherε_i, E sup_(f∈F)∑(Ef(X_i)−f(X_i))≤2E sup_(f∈F)∑ε_i f(X_i).
   Source: explains, §7.1, Lemmas 7.3–7.4
   Note: Symmetrization stated with f(X_k)−μf; measurability ignored in the text.

4. Separable real stochastic process
   A real process (X_t)_{t∈T} indexed by a metric space T is separable if there are a countable T₀⊆T and an almost sure event on which, for every t∈T, some sequence s_n∈T₀ with s_n→t has X_{s_n}→X_t. On that event sup_{t∈T}X_t=sup_{t∈T₀}X_t.
   Source: explains, §5.3, Definition 5.22
   Note: Definition of a separable process on a metric index set.
