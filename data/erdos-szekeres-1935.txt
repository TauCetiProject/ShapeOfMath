REQUIRED CONCEPT FRONTIER (7)

- Binomial coefficient: For integers 0≤k≤n, binom(n,k) counts the k-element subsets of an n-element set and equals n!/(k!(n−k)!).
- Convex position: A finite P⊂ℝ² is in convex position if no point of P is in the convex hull of the other points.
- Cups and caps of planar point sets: For planar points p₁,…,pₖ with strictly increasing x-coordinates, a k-cup has strictly increasing successive slopes, and a k-cap has strictly decreasing successive slopes.
- General position for planar point sets: A finite P⊂ℝ² is in general position here if no three distinct points of P lie on one line.
- Homogeneous set for a subset coloring: H⊆X is homogeneous for c if c is constant on the r-element subsets of H.
- König's infinity lemma: Every infinite rooted finitely branching tree has an infinite simple path starting at its root.
- Monotone subsequence: A strictly increasing subsequence has indices i₁<···<iₖ and values aᵢ₁<···<aᵢₖ; a decreasing subsequence reverses the value comparisons and retains increasing indices.

5. Homogeneous set for a subset coloring

6. Two-color uniform Ramsey number Rᵣ(s,t)
   Rᵣ(s,t) is the least N such that every red–blue r-subset coloring on N elements has a red-homogeneous s-set or a blue-homogeneous t-set; set it to ∞ if there is no such N.
   Source: explains, First proof, pp. 464–467

7. Finite simple undirected graph
   A finite simple graph is (V,E), where V is finite and E is a set of two-element subsets of V.
   Source: explains, First proof, pp. 464–467

8. Clique
   A set of vertices of a graph, every two of which are adjacent.
   Source: explains, First proof, pp. 464–467

9. Independent set in a graph
   A set of vertices in a graph containing no edge.
   Source: explains, First proof, pp. 464–467

10. Finite Ramsey theorem for uniform subset colorings
   For integers r≥1 and s,t≥r, there is N such that every red–blue coloring of r-subsets of an N-element set has a red-homogeneous s-set or a blue-homogeneous t-set.
   Source: explains, First proof, pp. 464–467

11. Esther Klein's five-point theorem
   Every set of five planar points in general position contains four points in convex position.
   Source: introduces, Introduction, p. 463

15. Erdős–Szekeres monotone subsequence theorem
   For integers r,s≥2, every sequence of (r−1)(s−1)+1 distinct real numbers has an increasing subsequence of length r or a decreasing subsequence of length s, both strict. The threshold is sharp.
   Source: introduces, Second proof, pp. 467–468
   Note: The stored statement uses distinct entries and strict monotonicity; the paper also permits equal ordinates with weak comparisons. The paper also credits Richard Rado for independent consideration of the monotone-subsequence problem.
   Origin evidence: The second proof, pp. 467–468, establishes the sharp monotone-subsequence threshold and explicitly credits Richard Rado with independent consideration. Preserve that shared credit; the earlier Ramsey theorem is separately credited to Ramsey.

16. Monotone-gap selection theorem for points on a line
   For r,s≥2, any binom(r+s−4,r−2)+1 distinct points on a line contain r points with nondecreasing consecutive gaps or s points with nonincreasing consecutive gaps.
   Source: introduces, Second proof, pp. 468–469
   Note: A descriptive title for a precisely stated intermediate result, not a standard eponym.
   Origin evidence: The second proof, pp. 468–469, states and proves the sharp monotone-gap selection result before the planar slope argument. No predecessor is credited for this intermediate standalone selection theorem. Its descriptive title is ours.

17. Erdős–Szekeres cups–caps theorem
   For r,s≥3, any binom(r+s−4,r−2)+1 planar points with no three collinear and with distinct x-coordinates contain an r-cup or an s-cap. This threshold is sharp for the cups–caps problem.
   Source: introduces, Second proof, pp. 469–470
   Origin evidence: The second proof, pp. 469–470, derives the sharp ordered-slope threshold and gives matching configurations; this is a contribution of the paper, unlike the Ramsey and Klein inputs explicitly credited earlier.

18. Erdős–Szekeres convex polygon theorem
   For each n≥3 there is N such that every planar set of at least N points in general position contains n points in convex position. The 1935 proof gives N≤binom(2n−4,n−2)+1.
   Source: introduces, Both proofs, pp. 463–470
   Origin evidence: The introduction poses the general convex-polygon question, credits Esther Klein for the five-point case, and claims two proofs of the new general existence theorem; pp. 464–470 supply them.

19. König's infinity lemma
   Every infinite rooted finitely branching tree has an infinite simple path starting at its root.
   Source: relies_on, Final paragraph, p. 470
   Note: The alternative existence argument is mentioned rather than proved in detail.

ADDITIONAL PREREQUISITES (31)

- Abelian group [definition]: A group whose operation is commutative.
- Bijection between sets [definition]: A function for which each element of the codomain is the image of exactly one element of the domain.
- Binary operation on a set [definition]: A function S×S→S.
- Binary relation on a set [definition]: A subset R⊆S×S; writing xRy means (x,y)∈R.
- Cartesian product of sets [definition]: A×B is the set of ordered pairs (a,b) with a∈A and b∈B.
- Commutative ring with identity [definition]: An abelian group under addition, together with an associative commutative multiplication with identity, distributing over addition. The zero ring is allowed.
- Convex subset of ℝᵈ [definition]: C⊆ℝᵈ is convex if (1−t)x+ty∈C whenever x,y∈C and 0≤t≤1.
- Euclidean space ℝᵈ [definition]: For d≥1, ℝᵈ consists of d-tuples of real numbers with distance dist(x,y)=(∑ᵢ(xᵢ−yᵢ)²)¹ᐟ².
- Extended nonnegative real numbers [definition]: The nonnegative real numbers together with a greatest element ∞. Sums involving ∞ equal ∞, and 0·∞ is taken to be 0 when integrating simple functions.
- Factorial [definition]: For n≥1, n!=1·2···n, and 0!=1.
- Field [definition]: A commutative ring in which 1≠0 and every nonzero element is invertible.
- Finite set [definition]: A set X is finite if it is bijective with {1,…,n} for some natural number n≥0; its cardinality is n.
- Function between sets [definition]: An assignment taking each element of a specified domain set to exactly one element of a specified codomain set.
- Graph distance [definition]: The distance between two vertices is the minimum length of a path joining them, or infinity if no such path exists.
- Group [definition]: A set with an associative binary operation, an identity element, and a two-sided inverse for each element.
- Intersection of a family of sets [definition]: Inside a specified ambient set, the elements belonging to every member of the family.
- Least upper bound in a partially ordered set [definition]: For A⊆P, its least upper bound is an upper bound s satisfying s≤b for every upper bound b of A, when such an s exists.
- Natural number [definition]: One of 0, 1, 2, …; natural numbers count finite collections.
- Nonnegative real square root [definition]: For t≥0, √t is the unique real number y≥0 satisfying y²=t.
- Ordered field [definition]: A field with a total order preserved by addition, in which the product of two positive elements is positive.
- Ordered pair [definition]: A pair (x,y) with distinguished first and second entries; (x,y)=(x′,y′) exactly when x=x′ and y=y′.
- Partial order [definition]: A reflexive, antisymmetric and transitive binary relation, usually written ≤.
- Path in an undirected graph [definition]: A finite sequence of adjacent edges joining successive vertices; a simple path has no repeated vertex. Its length is the number of edges.
- Real number [definition]: A real number is an element of a complete ordered field ℝ; completeness means every nonempty subset bounded above has a least upper bound.
- Rooted finitely branching tree [definition]: A rooted tree is a connected acyclic graph with a distinguished root. It is finitely branching if every vertex has finitely many children, meaning adjacent vertices one edge farther from the root.
- Sequence in a set [definition]: A function from the natural numbers, or the positive natural numbers, to that set.
- Set [definition]: A collection of distinct elements, regarded as one object.
- Subset [definition]: A⊆B means every element of A is an element of B.
- Total order [definition]: A partial order in which any two elements are comparable.
- Tree (graph theory) [definition]: An undirected graph that is connected, meaning any two vertices are joined by a path, and acyclic, meaning it has no cycle: no closed path of positive length repeating no edge and no vertex other than its common endpoints. Equivalently, any two vertices are joined by exactly one simple path; in particular a tree has no loops or parallel edges.
- Undirected multigraph [definition]: A vertex set and an edge set, with two unordered endpoints assigned to each edge; distinct edges can have the same endpoints and loops are allowed.
