LOCATED CONCEPTS (8)

1. Zorn’s lemma
   If every chain in a partially ordered set has an upper bound in that set, then the set has a maximal element.
   Source: explains, §5.6, Theorem 5.6.2(ii) and proof (i)⇒(ii), pp.152–154
   Note: Exposition and proof from the Axiom of Choice; not a priority claim.

2. Axiom of choice
   The set-theoretic axiom that every family of nonempty sets indexed by a set has a choice function, assigning to each index an element of the corresponding set; equivalently, a Cartesian product of nonempty sets is nonempty.
   Source: explains, §5.6, Theorem 5.6.2(i)
   Note: Statement of the axiom; not a priority claim.

3. Chain in a partially ordered set
   A chain in a partially ordered set P is a subset C⊆P that is totally ordered by the restricted order, so any two elements of C are comparable. The empty set is a chain.
   Source: explains, §5.1, Definition 5.1.6
   Note: Learning reference; not a priority claim.

4. Upper bound of a subset of a partially ordered set
   An upper bound of a subset A of a partially ordered set P is an element b∈P with a≤b for every a∈A; b need not belong to A.
   Source: explains, §5.1, Definition 5.1.6 (“majorizes”)
   Note: Learning reference; Bergman says x majorizes Y.

5. Maximal element of a partially ordered set
   An element m of a partially ordered set P is maximal if no x∈P satisfies m<x, that is, m≤x implies x=m. Unlike a greatest element, a maximal element need not be comparable with every element and need not be unique.
   Source: explains, §5.1, Definition 5.1.5
   Note: Learning reference, including the warning distinguishing maximal and greatest elements.

6. Hartogs’ lemma on ordinals not injecting into a set
   For every set X there is an ordinal α admitting no injection into X, equivalently not in bijection with any subset of X. The proof uses the replacement axiom but not the axiom of choice.
   Source: explains, §5.5, Lemma 5.5.14(i) and proof
   Note: Exposition; not a priority claim.

7. Well-founded recursion theorem
   Let X be a partially ordered set in which every nonempty subset has a minimal element, T a set, and r a rule assigning an element of T to each x∈X and function {y:y<x}→T. Then there is a unique f:X→T with f(x)=r(x,f|{y:y<x}) for all x. For ordinals this is transfinite recursion.
   Source: explains, §5.3, Lemma 5.3.4 and proof, p.127
   Note: Exposition for posets with descending chain condition; not a priority claim.

8. Order-preserving map between partially ordered sets
   A function f:P→Q between partially ordered sets is order-preserving (isotone, monotone) if x≤y implies f(x)≤f(y); it is strictly order-preserving if x<y implies f(x)<f(y).
   Source: explains, §5.1, Definition 5.1.3
   Note: Learning reference (isotone map).
