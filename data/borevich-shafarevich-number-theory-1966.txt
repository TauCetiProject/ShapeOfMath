LOCATED CONCEPTS (4)

1. Kummer’s power-sum criterion for the relative class number
   For an odd prime p, p divides the relative class number h⁻(p) of ℚ(ζ_p) if and only if p² divides ∑_(j=1)^(p−1) j^(2k) for some integer k with 1≤k≤(p−3)/2.
   Source: explains, Ch.5 §5.4 Theorem 3 with proof, pp.364–366
   Note: Full proof of the power-sum criterion for h*.

2. Kummer’s reduction of p | h(ℚ(ζ_p)) to the relative class number
   For an odd prime p, p divides the class number of ℚ(ζ_p) if and only if p divides the relative class number h⁻(p)=h(ℚ(ζ_p))/h(ℚ(ζ_p+ζ_p⁻¹)).
   Source: explains, Ch.5 §6.4 Theorem 2 with proof, p.376
   Note: Proof that l∤h* implies l∤h₀ (hence p|h ⇔ p|h⁻).

3. Kummer’s Bernoulli criterion for the relative class number of ℚ(ζ_p)
   For an odd prime p, p divides the relative class number h⁻(p) of ℚ(ζ_p) if and only if p divides the numerator of one of the Bernoulli numbers B₂,B₄,…,B_(p−3), written in lowest terms.
   Source: explains, Ch.5 §5.4 Theorem 4, p.366
   Note: Bernoulli reformulation of Theorem 3 via von Staudt and (8.11).

4. Kummer’s formula for the relative class number of ℚ(ζ_p)
   Let p=2m+1 be an odd prime, g a primitive root modulo p, g_s the least positive residue of g^s modulo p, θ a primitive (p−1)th root of unity and F(X)=∑_(s=0)^(p−2)g_sXˢ. Then the relative class number of ℚ(ζ_p) is h⁻(p)=|F(θ)F(θ³)⋯F(θ^(p−2))|/(2p)^(m−1).
   Source: explains, Ch.5 §5.1 formula (5.6), p.358
   Note: Derived from the analytic class number formula.
